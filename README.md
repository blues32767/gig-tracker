# 聽團網 — 下一場，在現場見。

> **INDEPENDENT MUSIC FIELD NOTES / TAIWAN**  
> 從第一首到最後一次安可，把喜歡的樂團，排進你的生活。

[聽團網 (gig-tracker)](https://blues32767.github.io/gig-tracker/) 是一個專為台灣獨立音樂愛好者打造的現場演出與歌單紀錄 Web App[cite: 1]。整合跨樂團行事曆、歷史演演出歌單與統計資料，讓你輕鬆探索樂團動態並記錄自己的現場足跡[cite: 1]。

---

## 🌟 主要功能

- 📅 **演出預告與行事曆**：即時掌握各大獨立樂團的最新演出資訊，支援「列表」與「月曆」兩種檢視模式[cite: 1]。
- 🎵 **歷史歌單檢索**：完整收錄過去演出的曲目 Setlist，並提供 Spotify 與 YouTube MV 聆聽連結[cite: 1]。
- 📊 **歌曲統計**：統計各樂團在現場最常演唱的熱門曲目排行榜[cite: 1]。
- 👣 **我的現場足跡**：標記你親臨現場的演出，資料儲存於瀏覽器（Local Storage），並支援 JSON 檔案匯出與匯入備份[cite: 1]。
- 🔍 **多重篩選與搜尋**：支援依樂團名稱、活動名稱、演出地點或歌曲進行快速關鍵字搜尋[cite: 1]。
- 🌓 **深色模式與響應式設計**：支援主題切換，針對手機與桌面端進行最佳化排版[cite: 1]。
